# OrCAD Electronic Circuit Design

전자회로 과목 및 개인 학습 과정에서 수행한 OrCAD/PSpice 실습 자료를 정리한 저장소입니다.

## 📚 학습 내용

- OrCAD Capture 회로도 작성
- PSpice 시뮬레이션
- Bias Point Analysis
- DC Sweep Analysis
- AC Sweep Analysis
- 증폭기 회로 해석
- 전자회로 특성 분석
- 회로 설계 및 검증

## 🛠️ 사용 툴

- OrCAD Capture CIS
- PSpice A/D
