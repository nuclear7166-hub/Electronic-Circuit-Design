# Electronic Circuit Design

전자회로 해석 및 설계 과목에서 수행한 OrCAD / PSpice 기반 회로 설계 및 시뮬레이션 프로젝트를 정리한 저장소입니다.

본 저장소에서는 단순 회로 구현뿐만 아니라 실제 산업 현장에서 사용되는 전자회로 설계 기법과 보호회로, 스위칭 회로, 트랜지스터 및 MOSFET 응용 회로를 학습하고 검증하였습니다.
